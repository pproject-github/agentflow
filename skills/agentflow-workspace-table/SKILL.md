# AgentFlow Workspace Table

在 Workspace 中需要展示查询结果、对比数据、字段列表、明细行时使用本技能。优先输出结构化 JSON，只有用户明确要求时才输出 Markdown 表格、CSV 或 TSV。

## 推荐格式

表格节点推荐接收：

```json
{
  "columns": ["日期", "崩溃设备数", "启动设备数", "崩溃率"],
  "rows": [
    ["2026-06-28", 35632, 6755735, "0.527%"],
    ["2026-06-29", 35821, 6767040, "0.529%"],
    ["2026-06-30", 25179, 5813363, "0.433%"]
  ]
}
```

也可以使用对象数组：

```json
[
  { "日期": "2026-06-28", "崩溃率": "0.527%" },
  { "日期": "2026-06-29", "崩溃率": "0.529%" }
]
```

## 输出到具名引脚

如果上游 agent 节点的某个输出引脚连接到了表格节点，比如用户要求“表格写入 `${table}`”，最终回复必须是 Workspace 输出协议：

```json
{
  "result": "给 Markdown/默认展示节点看的说明正文",
  "outParams": {
    "table": {
      "columns": ["列名1", "列名2"],
      "rows": [["值1", "值2"]]
    }
  }
}
```

不要把表格数据写进 `result`，除非表格节点连接的是 `result` 输出口。

## 内容规则

- 表格数据只放结构化数据，不要混入解释段落。
- 列名要短、稳定，适合作为表头。
- 行数很多时默认输出聚合结果或前 50 行，并在 `result` 中说明截断策略。
- 数字保持数字类型；展示单位可以放列名中，例如 `崩溃率(%)`。
- 不要输出 HTML 表格。

## Markdown / CSV 兼容

表格节点也能解析 Markdown 表格、CSV、TSV，但优先级低于 JSON。只有用户明确要求“Markdown 表格”或上游系统只能生成文本时才使用这些格式。
